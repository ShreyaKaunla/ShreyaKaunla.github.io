Eligify

Find the welfare schemes you qualify for, privatelyReact, Node.js, Python, SQLite, PostgreSQL, Web Crypto, LLM API
A citizen’s profile as the server would ever see it: vault locked
3,400+ schemes checked14/14 vault tests pass600,000 PBKDF2 iterations12 pipeline unit tests
  • A deterministic rule engine checks a profile against every scheme and states the exact reason for each rejection, with a link to the official portal.
  • Profiles are encrypted in the browser (AES-256-GCM). Lose the password and the recovery key, and the data is gone by design.
  • OCR runs on the device, so document photos never reach a server. Only the last 4 Aadhaar digits are kept.
  • A Python pipeline keeps the catalogue fresh: it fetches new and changed schemes from the ApiMitra API, has an LLM extract each eligibility rule with the exact source quote, runs automatic checks, and sends anything doubtful to a human reviewer before it reaches the app. It has 12 unit tests, including a mock API server.
  • PostgreSQL row-level security policies and an isolation test suite keep one citizen’s rows away from another’s.
